{{ _('The contact form') }}

{{ _('If you send a message through the contact page, we receive:') }}

  • {{ _('The category you picked and the message you wrote') }}
  • {{ _('Your email address — optional, and only used to reply to you') }}
  • {{ _('The page you were on when you opened the form, if you left that field filled in') }}
  • {{ _('Your interface language, so we know which language to reply in') }}

{{ _('The message is delivered to a private email inbox. It is not stored in a database and is never used for marketing. We keep messages for as long as it takes to deal with them; you can ask us to delete yours at any time.') }}

{{ _('Your IP address is used while the form is being submitted — to check the captcha and to enforce the rate limit described below — but it is not included in the message we receive and is not stored anywhere afterwards.') }}

{{ _('Spam protection') }}

{{ _('The contact form is protected by Cloudflare Turnstile. When you submit it, your IP address and a challenge token are sent to Cloudflare to confirm you are not a bot. We also keep a short-lived, in-memory count of recent submissions per IP address to rate-limit the form — that list holds at most 1,000 addresses for one hour and is erased whenever the server restarts. It is never written to disk.') }}

{{ _('Server logs') }}

{{ _('The site is hosted on Heroku, whose routing layer keeps standard short-term request logs (IP address, requested URL, timestamp, user agent) for operational and security purposes. We do not build profiles from them.') }}

{{ _('Cookies and browser storage') }}

{{ _('Strictly functional — never leaves your browser') }}

  • lang — {{ _('a cookie remembering whether you chose English or Spanish. Lasts one year.') }}
  • theme — {{ _('local storage holding your chosen site theme.') }}
  • munchstats.calcImportCollapsed — {{ _('local storage remembering whether you collapsed the calculator import box.') }}

{{ _('Nothing else') }}

{{ _('That is the complete list. MunchStats sets no analytics cookies, no advertising cookies, and no cross-site tracking cookies of any kind. Everything above is set by the site itself, stays in your browser, and exists only to remember a preference you chose.') }}

{{ _('Because the site is served through Cloudflare, Cloudflare sets a security cookie (__cf_bm) to distinguish human visitors from bots. It is used only to protect the site from abuse and is not used to track you across the web.') }}

{{ _('Almost none. Every script, stylesheet, font and image a normal MunchStats page needs is served from munchstats.com itself. {{ _('The MunchStats Android app') }}

{{ _('The app collects no personal data. It contains no analytics SDK, no crash-reporting SDK, no advertising SDK, and no tracking of any kind. It does not ask for your location, contacts, camera, files, or any other sensitive permission.') }}

{{ _('The only permission it needs is network access, used solely to download Pokémon statistics from munchstats.com. Those statistics are stored on your device so the app keeps working offline. That cached data stays on your phone, is never transmitted anywhere, and is deleted when you clear the app data or uninstall the app.') }}

{{ _('Our servers see the same thing any web server sees when the app requests data — an IP address and which statistics were asked for. We do not link those requests to an identity, because the app never sends one.') }}

{{ _('Tournament and player data') }}

{{ _('MunchStats displays competitive results — player names, placements, and team lists — gathered from publicly published sources: Pokémon Showdown usage statistics and public replays, Limitless, RK9.gg, the community-run VGCPastes spreadsheet, and Pokepaste. {{ _('If you are a player and want your name or team removed from the site, contact us and we will take it down.') }}
