{{ _('Pokémon Champions FAQ') }}

{{ _('Where does the Pokémon Champions in-game data come from?') }}

{{ _('The in-game usage data (the "[Champions] In-Game" formats) is not from Pokemon Showdown. It comes from the') }} Pokémon Champions Battle Data {{ _('API (championsbattledata.com), the only reliable source for real in-game battle data. The data is not stored on our end — it is cached directly from their API.') }}

{{ _('How often does the Pokémon Champions data get updated?') }}

{{ _('It is cached from their API and refreshed every 6 hours. Each Champions page also shows when the source last scraped the data, so you always know how current it is.') }}

{{ _('What is the usage rank trend on the Champions pages?') }}

{{ _('Each Champions Pokémon shows a graph of its daily in-game usage rank over the past week. Because the source publishes usage as a rank (not a percentage), the graph tracks rank over time — the higher on the chart, the more popular that day. The window automatically grows toward 30 days as more daily history becomes available.') }}
