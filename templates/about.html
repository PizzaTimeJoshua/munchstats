{{ _('Pokémon Champions FAQ') }}

{{ _('Where does the Pokémon Champions in-game data come from?') }}

{{ _('The in-game usage data (the "[Champions] In-Game" formats) is not from Pokémon Showdown, and it is not from a third-party API. We capture it ourselves: an automated system runs the game and reads the in-game Battle Data screens directly, one Pokémon at a time, for both Singles and Doubles.') }}

{{ _('How often does the Pokémon Champions data get updated?') }}

{{ _('Every night. A full sweep covers all 235 ranked Pokémon in both formats and takes about two and a half hours, after which the site picks up the new numbers. Each Champions page shows when the data was captured, so you always know how current it is.') }}

{{ _('What is the usage rank trend on the Champions pages?') }}

{{ _('The game publishes usage as a rank rather than a percentage, so the graph tracks that rank over time — higher on the chart means more popular that day. It shows one point per nightly capture, so it is short for now and grows by a day each night.') }}

{{ _('How accurate is it?') }}

{{ _('Every value is read off the screen, so it is checked rather than trusted. Move, item, ability and nature names are matched against the list of what is actually legal, and stat spreads are verified against the game\'s 66-point budget. Pokémon the game lists under one shared name — the four Gourgeist sizes, the two Meowstic, the Paldean Tauros breeds — are told apart from their sprites and movepools rather than guessed.') }}
